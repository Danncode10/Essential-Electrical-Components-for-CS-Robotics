# 🔌 Essential Electrical Components for CS Robotics

This course is designed to teach computer science students the **practical use** of key electrical components in robotics. Through hands-on Arduino-based activities, you'll gain confidence in using components like resistors, capacitors, diodes, transistors, and more—**without diving deep into electronics theory**.

---

## ✅ Prerequisites

Before starting, you should have:

- 🧠 **Basic Arduino Knowledge**  
  Understand `pinMode()`, `digitalWrite()`, `analogRead()`, and how to upload code using the Arduino IDE.

- 🔧 **Basic Breadboard Skills**  
  Know how to use a breadboard and jumper wires to build circuits.

- ⚡ **Basic Electrical Awareness**  
  Understand 5V, GND, and that too much current can damage components.

- 🧪 **Sensor Familiarity**  
  Experience using simple components like LEDs, buttons, or ultrasonic sensors.

> ❗ No soldering, formulas, or electronics theory required.

## 📘 Course Outline

| 1      | Resistors                    | Resistor (220Ω)               | LED blinking with and without resistor                |

| 7      | Voltage Regulators           | 7805 Voltage Regulator        | Power Arduino safely from 9V battery                  |

---

## 🛠 Final Project Challenge

Combine all components in a mini robotic power/control system:
- LED control (resistor)
- Button input (pull-down resistor)
- Stable sensor reading (capacitor)
- Motor control (transistor + diode)
- Power switching (relay)
- 9V battery to 5V (voltage regulator)
